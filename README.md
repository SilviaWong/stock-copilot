# 📈 Stock Copilot (股票/ETF 个人投资与决策复盘助手)

专为个人自用打造的 A 股 / 场内 ETF 交易记录、保本成本加权摊薄、落袋盈亏归因与加仓决策辅助系统。

---

## 🌟 核心功能一览

1. **真实成本加权摊薄**：
   - 自动将多笔建仓、加仓、手续费计入成本均价；
   - 现金分红自动冲减总投入本金，进一步拉低保本单价。
2. **落袋盈亏（已实现净收益）计算**：
   - 部分卖出或清仓时，精准核算每一笔落袋赚了多少钱，统计实战胜率与盈亏比。
3. **风控与拦截**：
   - 卖出数量超出当前实际可用持仓时自动拦截，防止误录。
4. **交易流水撤销与自动对账**：
   - 删除任意一笔历史流水，系统自动按时间正序重新回放全量交易，确保持仓分毫不差。
5. **🧮 加仓成本摊薄与回本测算器（决策辅助建议）**：
   - 输入“拟在 X 元补仓 Y 股”，实时推演：
     - 加仓后新持仓均价拉低至多少；
     - 相比加仓价仅需反弹百分之几即可回本；
     - 提供是否有效摊薄的量化辅助评估。
6. **止盈止损线监控**：
   - 自定义各标的的目标止盈价与风控止损价，计算预期收益率与最大回撤。

---

## 🛠 技术架构

* **后端**：Java 17 + Spring Boot 3.3.4 + MyBatis-Plus 3.5.7
* **数据库**：SQLite 3（数据文件直接存储于 [`data/stock.db`](./data/stock.db)，零安装无需 MySQL 服务）
* **前端**：Vue 3 + Vite + Element Plus + Axios
* **数据设计与 SQL 脚本**：详见 [`doc/db/`](./doc/db/)

---

## 🚀 本地一键启动指南

### 1. 启动后端 (Spring Boot)

打开第一个终端窗口：

```bash
cd backend
mvn spring-boot:run
```
后端服务将在 `http://localhost:8080` 启动，自动检测并初始化 `data/stock.db`。

---

### 2. 启动前端 (Vue 3 + Vite)

打开第二个终端窗口：

```bash
cd frontend
npm run dev
```
启动成功后，浏览器访问 **`http://localhost:5173`** 即可立即开始使用！
（所有 `/api` 接口请求已通过 Vite 反向代理自动转发给后端 8080 端口，无需配置跨域）。
